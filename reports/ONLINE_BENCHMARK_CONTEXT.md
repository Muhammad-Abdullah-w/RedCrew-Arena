# Online benchmark context

> These numbers are quoted from the original public sources. They were **not** generated by RedCrew Arena and are never merged into the executed offline result tables.

## Public benchmark comparison

| Benchmark / configuration | Scope | Reported utility | Reported attack success | Interpretation |
|---|---:|---:|---:|---|
| InjecAgent, prompted GPT-4 (ReAct), base | 1,054 cases | Not reported in the main ASR table | 23.6% ASR-valid | Capable prompted agents remained vulnerable to indirect injection. |
| InjecAgent, prompted GPT-4 (ReAct), enhanced | 1,054 cases | Not reported in the main ASR table | 47.0% ASR-valid | A stronger prefixed injection approximately doubled total ASR-valid. |
| InjecAgent, fine-tuned GPT-4, base / enhanced | 1,054 cases per setting | Not reported in the main ASR table | 6.6% / 7.1% ASR-valid | Lower, but non-zero, risk remained. |
| AgentDojo, GPT-4o baseline agent | 97 benign tasks; 629 security cases | 69.00% benign; 50.08% under attack | 47.69% targeted ASR | Utility and security must be reported together. |
| AgentDojo, GPT-4o, no defense (defense study) | 629 security cases | 69.00% benign; 50.01% under attack | 57.69% targeted ASR | Strong attack used for defense comparison. |
| AgentDojo, GPT-4o, tool filter | 629 security cases | 73.13% benign; 56.28% under attack | 6.84% targeted ASR | Tool isolation was highly effective, but the paper identifies overlap/dynamic-planning limitations. |
| AgentDojo, GPT-4o, prompt-injection detector | 629 security cases | 41.49% benign; 21.14% under attack | 7.95% targeted ASR | Low ASR came with a large utility penalty from false positives. |

## Why RedCrew Arena does not claim direct leaderboard equivalence

RedCrew Arena's bundled run uses a deterministic attack-following oracle to test the control plane. InjecAgent and AgentDojo use live LLM agents and benchmark-specific execution environments. The case semantics, success validators, and model stochasticity differ. Therefore, the project reports its own results as an engineering regression benchmark, not as a model leaderboard result.
